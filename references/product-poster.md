# 产品海报规范

## 模板拆解结论

参考模板是一组 A4 竖版、浅灰白科技底的销售指导页。它不是“单一大图广告”，而是把产品彩页压缩成一张可快速阅读的数据型海报。

### 内容框架

1. 品牌区：左上 Logo，留足安全空间。
2. 主标题：产品/平台名 + 一句价值主张，通常两行；核心词用品牌绿强调。
3. 导语或关键价值：一句总论，或 2–3 条短价值点。
4. 核心证据区：产品 A/B 对比、雷达图、柱状图、关键数字或架构图；每个图必须有结论句。
5. 方案/场景区：适用场景、行业、型号/配置、核心优势，使用表格或卡片承载。
6. 页脚：口径说明、来源、上市信息或行动提示。

### 视觉系统

- 背景：#F4F8FA 至白色，叠加 5%–10% 透明度的云、芯片、服务器或网格线稿。
- 主色：示例品牌蓝 #0C3F91；强调绿约 #72BE2D；辅助浅蓝 #DCECF5。
- 顶底使用蓝绿波浪或弧形品牌带，形成系列识别。
- 内容采用单列纵向流，模块间距明显；模块标题使用蓝底标签或蓝色图标。
- 图表统一蓝/绿两组，避免彩虹色；比较图必须明确对象、指标、单位、结论和数据来源。
- 信息密度可高，但白底区必须保留 8%–12% 外边距和稳定网格。

## 内容提炼规则

- 主标题不超过 22 个汉字；价值主张优先写“对象 + 优势 + 场景”，避免空泛口号。
- 导语不超过 60 字；价值点每条 16–32 字，最多 3 条。
- 选择 2–4 个最能支撑购买决策的指标。只有原文给出基准和口径时才写“提升/降低 X%”。
- 规格表最多 5 行、4 列；更多规格转移到彩页或附页。
- 雷达图适合 4–6 个同量纲评分维度；没有真实评分时不可凭感觉绘制。
- 没有足够数据时，用“能力卡 + 场景卡”代替伪图表。

## 推荐版式比例

- 品牌区 6%；标题与导语 18%；证据总览 28%；详细图表 24%；方案表 18%；页脚 6%。
- 关键数字字号应为正文的 1.8–2.5 倍；模块标题约为正文的 1.15–1.3 倍。
- CTA 不是必需项；销售指导页更适合“了解详情/联系销售”的轻量页脚，不要抢占证据区。

## 禁止项

- 不把整页做成深色客户案例风；不使用大面积客户实景作为背景。
- 不堆超过 4 种图表，不使用无来源的“行业第一”“遥遥领先”。
- 不直接把 PDF 页面截图当成新海报；必须重组信息层级。

## 已落地版式（v1.2 起为默认）

产品版按“品牌区 → 大标题 → 副标题 → 导语 → 价值点 → 指标卡 → 界面实拍 → 能力卡 或 套餐内容表 → 底部 CTA 条”顺序，**纵向满版填充**，底部不留空白。

### 套餐内容表：排版要点

一个套餐包含多款物料时，用 `package_table` 而不是能力卡，把"型号／物料／能力"对应关系讲清楚：

- **列宽固定**：组成 130px / 物料 176px / 能力 1fr。能力列给足宽度，避免要点折行出孤字（如"发"单独占一行）。
- **每格要点控制在 3 条、每条 ≤ 26 个汉字**：超出会顶穿海报底部，表格是高密度区块，宁可少写。
- **表尾必写共用说明**：所有物料共同适用的条款（如"均含 1 年基础运维服务与软件升级授权"）放表尾，避免在每个物料里重复。
- **组成行数建议 2 行**：3 行时要点需压到 2 条。配 `.pkg{flex:1;grid-template-rows:auto 1fr 1fr auto}` 让行自动撑满剩余高度。
- 数据必须逐条对齐原始文档，物料名称、版本号（V1.0 / V2.0）、数量口径（如"每 1000 点一套"）不能改写。内部材料里的接口人、内部系统路径、发文编号一律不进海报。

| 区块 | 字段 | 规则 |
| --- | --- | --- |
| 左上公司 Logo | `company_logo` | 必填。固定左上角、白底圆角胶囊；先用 alpha 通道裁掉透明留白再引用，否则缩到 46px 高会显得极小 |
| 角标 | `badge` | 右上角胶囊，如“Q4 冲刺套餐”，默认值 `Q4 冲刺套餐` |
| 大标题 | `title` + `title_font` + `title_effect` | 浅底海报默认 `youshe` × `tech-shadow-light`（深蓝→青渐变填充 + 硬边挤出阴影）。**不要用深色版 `tech-shadow`**：白底上浅色填充会与背景糊在一起 |
| 副标题 | `subtitle` | 支持 `{片段}` 高亮（红色 #E8442F），用于突出价格/点数 |

### 大标题清晰度规则（v1.3 起）

挤出阴影会吃掉细笔画的字口，笔画越密越容易糊。浅底产品海报按下面顺序挑组合：

| 组合 | 可读性 | 适用 |
| --- | --- | --- |
| **`block-tech`（斜切渐变块反白）× 任意粗壮字体** | 最好 | **浅底默认推荐**：颜色由色块承载，字是纯白反白，等于把标题做成"深色焦点块"，同时解决清晰度和版面焦点 |
| `dual-tone`（双色分阶压印）× 粗壮字体 | 最好 | 不想要色块、要更"平"的版面时用；墨蓝+品牌绿分色，零模糊阴影 |
| 任意字体 × `plain`（深色实心、无阴影） | 最好 | 需要"一眼看清"时 |
| 粗壮字体（思源黑体 Heavy / 思源宋体 Heavy）× `tech-shadow-light` | 较好 | 想保留渐变填充 + 挤出阴影的科技感 |
| 优设标题黑 × `tech-shadow-light` | 一般 | 系列一致性优先时才用 |
| `outline-mix`（空心描边）× 细笔画字体 | 一般（远看弱） | 潮流场合 |
| 细笔画字体（得意黑、霞鹜文楷）× 任何挤出阴影 | 差 | 避免 |

**自检方法**：把最终标题连同效果一起截图 1:1 看，如果"服、刺、套"这类多笔画字的第一眼识别需要停顿，就换粗壮字体或换效果。不要只在小图上看效果。

### 中间指标卡：优先用色块而非白卡

4 个数字排成 4 张白卡会显得平淡、像表格。改成 **2 张品牌色渐变卡**（`metric_groups`）：

- 左卡深蓝渐变、右卡品牌绿渐变，反白字，卡片内用 1px 半透明白竖线分隔两组值；
- 卡片左上角加 10.5px 大写间距的小标签（`cap`，如「套餐规格」「服务内容」），给卡片一个语义标题；
- 卡内加两个半透明白圆形装饰，避免纯色块显得死板；
- 值的字号 28px、标签 12.5px，标签 `white-space:nowrap` 防止换行破坏对齐。

这样海报从上到下形成「深色标题块 → 深色/绿色指标卡 → 白色截图与能力卡 → 深色 CTA 条」的节奏，中间不再是一片浅色。
| 价值点 | `highlights` | 最多 4 条，2×2 网格。特性数尽量凑够 4 条，3 条会在第 4 格留空 |
| 指标卡 | `metrics`（4 张单卡）或 `metric_groups`（2 张大卡） | `metric_groups` 每卡并排放 2 组「值 + 标签」，用虚线分隔；拆成 2 张卡比 4 张单卡更聚焦，读起来是"两句话" |
| 界面实拍 | `screens`（数组）或 `product_screens`（单图） | `screens` 为 4 栏网格，每项 `{img, label}`，绿色标签条；优先用彩页 PDF 里按坐标裁出的高清单图，比整条拼接更清晰。**4 张图的比例必须一致**（模板按 1.69 排版），换图时若比例不同要**上下补白对齐、不要裁切**，否则 4 条绿标签的高度会参差 |
| 标题 | `screens_label` | 截图区标题，避免与截图内部自带的文字重复 |
| 能力卡 | `sections` | 2×2 网格，撑满剩余高度。用 `points`（3 条要点）比用 `body`（段落）更饱满；`points` 存在时忽略 `body` |
| 套餐内容表 | `package_table` | **提供时替代 `sections`**（`flex:1` 撑满剩余高度）。3 列表格：`列1 组成名`（130px，带 01/02 序号徽章）/ `列2 套餐物料`（176px）/ `列3 关键能力`（1fr，3 条要点）。表头深蓝渐变白字，表尾浅蓝底写共用说明。适合"一个套餐含 N 款物料"的销售页——把型号关系和物料清单一次讲清，比一堆能力卡更有"清单感" |
| 底部 CTA 条 | `cta` + `source_note` + `price_note` | 满幅蓝底+顶部绿线：`cta` 为粗体口号（左对齐）、`source_note` 放上市/退市时间与口径说明（左对齐）、`price_note` 为价格声明（**右对齐、右下角**，如「（价格为总代价，最终报价以内部报价系统为准）」）。**不要再单独放绝对定位的页脚** |

### 从彩页 PDF 提取界面截图的正确做法

先定位文字块拿到证据区坐标，再按图片 bbox 高倍渲染裁切，而不是整页截图：

```python
import fitz
pg = fitz.open(pdf)[0]
for b in pg.get_text("blocks"):                     # 找到“产品效果：…”所在文字块
    if "产品效果" in b[4]: print(b[:4])
boxes = [tuple(pg.get_image_bbox(x)) for x in pg.get_images(full=True)]   # 4 张界面图坐标
pix = pg.get_pixmap(matrix=fitz.Matrix(4, 4))       # 4 倍渲染保证清晰
```
