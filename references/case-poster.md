# 客户案例海报规范

## 模板拆解结论

参考模板为 1080×1440 的 3:4 竖版系列。其核心是“联合品牌 + 统一 campaign 口号 + 场景主视觉 + 方案成果 + 客户背书”，视觉上采用深蓝霓虹科技风，与产品海报的浅底数据页完全区分。

### 内容框架

1. 联合品牌区：客户 Logo、分隔线、供应商品牌 Logo，位于左上。
2. Campaign 标题：固定系列口号两行，核心产品/行业词用亮绿突出。标题 JSON 中用 `{片段}` 标记需要高亮的词，例如 `护航{AI算力产业链}拔节生长`；未标记时整段白色显示。
3. 方案价值卡：1–2 个方案标签，每个标签下是一句价值说明。
4. 场景主视觉：客户厂区、园区、机房、建筑或业务场景，纵向占画面约 32%–40%。
5. 客户背书卡：客户名、行业定位、案例摘要。
6. 转化入口：右下二维码，可带“扫码了解详情”；没有真实链接时保留占位框，不生成假码。

### 视觉系统

- 背景：顶部深海军蓝 #00183F，底部 #003E8A；主视觉与背景用蓝色渐变融合。
- 强调：科技青 #00CFE8、品牌绿 #00D98B、白色正文；标题可使用轻微斜体和横向速度光效。
- 卡片：半透明深蓝面板，1–2px 青蓝发光描边，斜切角或六边形标签；发光只服务层级，不覆盖正文。
- 主图需真实、可识别且与客户业务相关。可做蓝色调色和暗角，但不能修改建筑标识或伪造项目现场。
- 系列海报固定标题、色板、边框语言和信息位置，只更换客户 Logo、场景、方案标签与案例内容。

## 文案提炼规则

- 客户名：使用正式简称，2–10 字为宜；全称可进入小字。
- 行业定位：一行，建议 10–20 字。只有原文有依据时才能写 TOP、头部或领先。
- 方案价值：优先表达业务结果，其次表达技术动作。例如“研发数据集中管控，实现安全跨区协作”。
- 摘要采用“挑战 → 方案 → 结果”的顺序，90–150 字；没有量化结果时写可验证的能力变化，不编造节省比例。
- 有两个产品时使用并列价值卡；一个产品时用居中的单卡，避免为了对称复制内容。

## 推荐版式比例

- 联合品牌 8%；Campaign 标题 17%；价值卡 14%；场景主视觉 33%；客户背书卡 25%；底部安全区 3%。
- 主标题约 58–76px；客户名 58–72px；行业定位 28–34px；摘要 24–28px，行距 1.55–1.7。
- 海报外边距至少 48px；二维码建议 160–190px，四周静区不少于码宽的 4%。

## 禁止项

- 不套用产品海报的白底表格和密集图表风。
- 不从互联网擅自抓取客户 Logo、厂区图或人物图用于对外材料；缺素材时明确请求或使用占位。
- 不让生成式模型重绘客户 Logo、二维码或含商标的建筑招牌。
- 不把技术清单当摘要；读者应先看到客户是谁、解决了什么、带来什么变化。
