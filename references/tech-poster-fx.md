# 科技海报特效层

案例海报参考设计师版时，使用可复用的 Tech Poster FX 组合，不把视觉效果写死在单张海报里。

## 标题层

- 主体字使用清晰展示字体；复杂中文优先保证内部留白。
- 白色主标题使用三层以内蓝色/青色下方挤出：浅青边缘 → 亮蓝主体 → 深蓝底层。避免强模糊光晕覆盖笔画。
- 关键词用 `{关键词}` 标记，使用品牌绿独立填充，并使用同方向但更轻的青绿挤出。
- 标题下方增加一条细青色速度线；速度线不得穿过文字主体。
- 标题效果必须由 `.h1art` 专用规则控制，覆盖模板旧 `text-shadow`、`font-style: italic`。

## 背景层

按层叠顺序实现：

1. 深海军蓝基底，避免单色纯蓝。
2. 左上蓝色径向光晕，模拟品牌能量入口。
3. 标题下方横向/斜向能量带，连接标题与方案卡。
4. 细弧形光轨和少量能量节点，建立方向性；节点不超过 3 个。
5. 主体图区域加入冷色聚光，保留真实建筑/设备细节。
6. 中下部使用低透明度斜向网格或点阵，增加空间纵深；透明度不高于 0.35。
7. 底部信息卡区域压暗，保证正文对比度。

不要用大面积发光、重噪声或高透明网格覆盖客户 Logo、标题和正文。

## 方案卡与信息卡

- 方案卡采用蓝色半透明面板、青色细边框、六边形标签；卡片正文尽量压缩为 2 行短句。
- 不对父级卡片使用会裁掉标签的 `clip-path`；切角效果使用伪元素或 SVG 边框实现。
- 客户 Logo 如果是深色图形且背景为深蓝，增加白色保护底，不改动 Logo 本身。
- 客户背书卡使用切角轮廓、双层边框和轻微内发光；不能让发光压过正文。

## 对照验收

生成优化版后，对照设计师版逐项检查：

- 标题是否有主体/挤出/高亮/速度线四层关系。
- 背景是否有至少三种方向性光效，而非单一渐变。
- 真实客户图片是否仍可识别，Logo 是否清晰。
- 方案卡标签是否完整，未被父级裁切。
- 「核、数、据、管、理、安」等复杂字是否保持内部留白。
- 正文、二维码占位和客户名是否满足安全边距。
