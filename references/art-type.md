## 字距规则（防笔画粘连，已实测验证）

- 超宽超重字体（优设标题黑、庞门正道标题体）：**0 至 +0.02em 正字距**。负字距会让相邻字形笔画相贴（「基座」类复杂字形实测完全粘连）。
- 常规黑体（思源黑体、得意黑）：-0.02em。
- 楷体/手写类（文楷、黄油体、宋体）：-0.01em；马善政楷书 0。
- 行高 0.95–1.1；标题尽量 8 字以内；需要斜体感用 CSS `skewX`（0.02–0.18），不用伪斜体 `font-style:italic`。
- 大标题最小字号：展示字体不低于 1080px 宽画布中的 44px。

## 清晰度保护规则

- `plain` 纯净大字必须关闭 `text-shadow`、`filter`、伪斜体和额外描边；不能让案例模板原有的发光样式覆盖它。
- 复杂中文（含「核、心、数、据、管、理、安、全」等多部件字）禁止统一使用负字距；优设标题黑使用 `+0.015em`，庞门正道标题体使用 `+0.01em`。
- 优设标题黑的卡片预览字号不低于 40px，最终 1080px 海报标题字号不低于 70px；如出现内孔堵塞，优先降低字重/字号或增加字距，不使用模糊阴影补偿。
- 案例模板的通用 `h1` 发光、投影和 `font-style: italic` 必须被 `.h1art` 专用规则覆盖；`.h1art` 以 `text-rendering: geometricPrecision` 和抗锯齿为默认。
- `stroke` 描边默认 2px，`extrude` 默认 6 层；复杂中文不叠加描边与强发光。

## 标题分段高亮

- 在 `campaign` 或 `title` 字段中，用半角花括号标记需要强调的词：`护航{AI算力产业链}拔节生长`。
- 渲染器将花括号内容转为 `.hl`，案例海报默认品牌绿 `#00D98B`，产品海报默认强调绿 `#72BE2D`。
- 花括号仅用于标记，不会显示在成品；标题文字中的 HTML 会被转义，避免素材内容注入 HTML。
- 仅高亮关键词，不要整句高亮；建议每行 2–8 字，避免绿色文字削弱标题层级。

|---|---|---|---|

| gradient | 渐变填充 | 通用 | background-clip:text |
| dual-tone | 双色分阶压印 | **浅底** | 主词墨蓝 #0A3A7B + `{}` 关键词品牌绿 #4FA312，白/暗双向 1px 压印高光，零模糊阴影，清晰度最好 |

| tech-shadow | 科技主题阴影 | **暗底** | 设计师版风格：浅色填充 + 蓝色下方挤出 + 绿色关键词层 + 标题速度线 |

| neon | 霓虹发光 | 暗底 | 仅暗底使用 |
| skew | 斜切冲击 | 通用 | skewX + 错位投影 |

标题文案里的 `{}` 标记是**所有效果共用的分色入口**：`rich()` 会把它转成 `.hl`，各效果再给 `.hl` 一套独立配色。所以「换字体 + 换效果 + 换配色」可以完全解耦。

## 选版流程（SKILL.md 工作流第 4 步）

1. 拿到海报大标题文案后，先运行：

```bash
python3 business-poster-generator/art-type/scripts/make_select_page.py "标题{关键词}文案" --output <输出目录> --default-fx block-tech
```

`--default-fx` 指定打开页面时默认选中的效果。文案里的 `{关键词}` 会转成 `.hl` 片段，用于预览各效果的**分色配色**，不要漏写。

2. 打开 `<输出目录>/select.html`，将页面交给用户挑选「字体 × 效果」。
3. 用户选定后，把选择写入 brief JSON 的 `title_font`（默认 `youshe`）与 `title_effect`（默认 `plain`），再运行 `scripts/render_poster.py` 渲染成品。

依赖：fonttools + brotli（仅选版脚本需要；渲染器只引用完整字体文件，无额外依赖）。
